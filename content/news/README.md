# Как опубликовать материал

Один файл в этой папке это одна публикация. Имя файла становится адресом:
`nvme-protiv-ssd.md` откроется по адресу `/novosti/nvme-protiv-ssd`

Шаблон:

```markdown
---
title: "Заголовок материала"
date: 2026-08-05
rubric: novosti
description: "Одно предложение: оно попадёт в превью и в поисковую выдачу"
author: Редакция ServerCalc
---

Первый абзац это лид, он задаёт тему.

## Подзаголовок

Дальше обычный markdown: абзацы, списки, ссылки, таблицы, цитаты
```

## Правила

**Кавычки в заголовке.** Если в `title` или `description` есть двоеточие, значение обязано быть в кавычках. Иначе разбор ломается, материал не попадёт в ленту, а в лог сборки уйдёт предупреждение

**Рубрики:**

- `novosti` — что происходит на рынке и у провайдеров
- `obzory` — как выбирать и на что смотреть
- `ceny` — журнал изменений цен в каталоге

**Дата** в формате `ГГГГ-ММ-ДД`. Материалы сортируются по ней, новые сверху

**Поле `updated`** необязательное, добавляется при существенной правке старого материала: `updated: 2026-09-01`

## Чего не должно быть в текстах

- ничего про VPN и обход блокировок, это закрытая тема на русской версии
- упоминаний оплаты картой РФ и рублями, эта ось убрана с сайта целиком
- слов «лучший» и «номер один» без ссылки на методологию сравнения
- скопированных описаний тарифов с сайтов провайдеров

Проверить всё это разом: `npm run build && npm run start`, затем `npm run check`

## После добавления файла

Сборка статическая, поэтому нужна пересборка: `npm run build`. Материал появится в ленте, в блоке на главной, в sitemap и получит микроразметку Article автоматически
